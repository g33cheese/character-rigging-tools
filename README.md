# Character Rigging Tools

A collection of Maya Python tools and character rigging workflows, including mGear build automation, skinning utilities, and facial corrective systems.

## Repository Contents

### [Facial Rigging](./facial_rigging/)

Tools for facial rigging workflows, including automated corrective blendshape processing and MetaHuman facial control connections.

### [mGear Pipeline](./mgear_pipeline/)

Tools for mGear rigging workflows, including build preparation, skinning data management, and custom rig processing.

### Technologies

- Autodesk Maya
- Python
- mGear
- ngSkinTools
- MetaHuman
